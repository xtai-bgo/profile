# assets

## Portrait

Put the portrait photo here as `portrait.jpg`.

- Portrait orientation, 4:5 ratio, about 800×1000 px, under 300 KB.
- The page loads `assets/portrait.jpg`; until the file exists an initials tile shows in its place.
